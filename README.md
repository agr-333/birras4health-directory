# Birras4Health · Directorio

Web estática para publicar en GitHub Pages.

## Archivos
- `index.html`
- `styles.css`
- `app.js`
- `data.js`

## Qué incluye
- búsqueda por texto
- filtros por categoría, ubicación y LinkedIn
- ordenación
- tarjetas de perfiles
- fichas individuales mediante URL con hash (`#persona/...`)
- panel lateral con resumen del ecosistema

## Cómo publicarla en GitHub Pages
1. Crea un repositorio nuevo.
2. Sube todos los archivos de esta carpeta.
3. En GitHub entra en `Settings` → `Pages`.
4. En `Build and deployment`, elige:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Guarda y espera a que GitHub te genere la URL.

## Nota
El contenido procede del historial del grupo y algunas fichas son inferencias basadas en mensajes y presentaciones del chat. Revisa antes de publicar en abierto.
